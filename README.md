 Online Cafe 38  ☕️
This is a simple online café menu project built with vanilla JavaScript, HTML, CSS, and Bootstrap.
The app allows users to browse food items, customize them with toppings, and add them to the cart.

🔧 Frontend
- Built with HTML, CSS, JavaScript
- Styled using Bootstrap and custom CSS
- Bundled with Webpack

Includes:
- Dynamic category filtering
- Toppings selection with real-time price updates
- Cart functionality stored in localStorage

🛠 Backend
A basic Express.js server

Supports:

- GET /orders to fetch all orders
- POST /orders to receive new orders

Orders are saved in memory (no database)
